# CEX Competitive Intelligence Dashboard

A competitive intelligence dashboard tracking signals across global crypto exchanges in Singapore and Australia markets.

**Live demo:** https://richardlesmana.github.io/cex-intel

## What it does

Aggregates and visualizes signals across competitor exchanges:
- New product launches
- Geographic expansion
- Regulatory licenses obtained
- App store rating trends over time

## Stack

- Python scrapers (run monthly via Claude Code)
- Static JSON data layer
- Vanilla HTML/CSS/JS dashboard
- Hosted on GitHub Pages
